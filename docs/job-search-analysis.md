## Analysis

**Most common requirements.** Nearly every posting asks for a portfolio, and most ask for hands-on design experience with a game engine. Internships and associate roles accept academic projects, mods, and personal projects as experience. That makes my Roblox work and a finished engine project very valuable.

**Where I stand out.** Few new graduates have run a profitable game-adjacent business. My Roblox UGC work proves I understand what players want, can ship on a schedule, and can improve designs from real data. It fits Roblox studios like Gamefam especially well. OC Forge also shows I can build a working AI tool, which Next Genium explicitly asks for.

**Biggest gaps.** A polished solo game in an engine (my Unity maze is a team prototype), Lua scripting in Roblox Studio, and experience with design documentation and team tools. These come up again and again and are fixable within a few months. See the [skills gap analysis](skills-gap-analysis.md).

**Market observations.**

- Truly entry-level, fully remote game design roles are rare. Many "associate" titles still ask for 1–2 years, which can include academic and personal work.
- Internships are the clearest entry point, but they require current enrollment, so I should apply before I graduate in December 2026.
- Roblox studios are a strong match because my experience is directly relevant there.
- Pay ranges vary widely: from about $36.50/hr for internships to $140K+ for Roblox's early-career program.
